# Crow & Smith Law — website concept

A responsive sales demonstration prepared by New Bern Websites for Crow & Smith Law.

## Preview and hosting

Buildless HTML, CSS, and JavaScript. Serve the repository root with any static web server, or deploy to the linked Vercel project. No installation or build step is required.

## Demonstration behavior

- Four interactive practice-area overviews.
- Attorney biography dialogs, real portraits, and staff introductions.
- Consultation form with browser validation and a clearly identified demo completion state. No form data is sent or persisted.
- Google Maps office embed, directions, phone and email links.
- Responsive navigation, mobile contact bar, keyboard-friendly dialogs, and reduced-motion support.
- No checkout, outreach, analytics, backend, or real inquiry collection is enabled.
- Search indexing is disabled in HTML, HTTP headers, and robots.txt.
